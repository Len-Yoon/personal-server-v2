## 2. 핵심 요약

메모 API·PostgreSQL·매시간 백업·맥북 반출·빈DB 복구를 구현함. 실제 백업4행을 별도DB에복원해전체데이터hash일치, 복원후API DML, 비어있지않은대상재복원거부, 기존37개자원UID·Secret hash·샘플보존을확인함. RTO11.471초는빈DB준비후복원Job부터API·데이터일치까지의소형실습측정치이며SLA가아님.

검토발견에따라credentials초기화·build context축소·반입원자성·64MiB반출상한·앱권한분리·JobTTL·PVC재마운트·접속안내·CEL타입검사를보완함. checksum손상·보관24개·락·실패정리는단위검증과실제복원검증을구분함.

초기백업은fsGroup/setgid권한검사에서실패함. OnRootMismatch와소유확인후0700정규화로수정함. 이후OrbStack엔진조회·localhost응답장애가발생해사용자전체재시작승인후정상stop/start를실행함. cluster/container ID는보존됐고DB는재시작후자동복구로그와기존데이터를확인함. 종료된V2registry만같은ID로다시시작하고unless-stopped를설정함. 새Job의최초DB접속실패는SELECT1준비재시도후성공했으며백업·복원쓰기자체는재시도하지않음.

## 5. 확인 필요 사항

- 같은맥북의PVC·반출은물리재해복구나HA가아님. 별도장비백업·PITR·복제는미구현임.
- 정기CronJob은매시간UTC이며절전·실패때1시간RPO를보장하지않음.
- RTO실측은4행소형데이터이며환경설치·이미지반입시간은제외함.
- 기존관측수집대상확장과구분하여새API는metrics endpoint를제공함.
- 최종CI·독립검토·병합·main동기화결과는최종PR및Git밖실행기록으로확인함.
