## 5. 확인 필요 사항

- YouTube 원격 제목 조회는 egress 제한으로 실패 시 기본 제목을 사용함. 외부 재생은 브라우저 인터넷 연결에 의존함.
- 노드 로컬 PVC이며 다른 노드 복원·외부 백업·HA·전체 폐쇄망 설치는 미수행임.
- PR·CI·병합 및 병합 후 로컬 검증은 후속 결과를 확인해야 함.
