| 역할 | 담당 범위 | 결과 | 비고 |
|---|---|---|---|
| 주 담당·구현자 root | CLI·안전 경계·검증 도구·CI·문서·실행 | 자기 검증 수행 | 독립 검토로 집계하지 않음 |
| 구현자 manifests | apps/·platforms/ 명세 | Kustomize·Helm 렌더 자기 검증 | 파일 소유권 이관 후 root 통합 |
| 독립·전문 검토자 review | diff·삭제·인증·DB·복구·CI 경계 | 1차/재검토 지적 수정 반영, 최종 검토 예정 | 대상 구현 파일 수정 없음 |

지적 수정: 삭제 대상 전체 inventory·ID 검증, 생성 journal·부분 정리, Deployment UID 복구 검사, 기존 비밀값 ignore 유지, Argo 자원 소유·목적지 검사, sync 요청 식별자, 실제 포워딩 준비 확인을 반영함. 테스트·CI·독립 검토·사용자 수신은 서로 다른 증거임.

## 5. 확인 필요 사항

- 비공개 Git 인증·GitOps sync·drift 원복·실패 Git 배포·Git revert 복구는 연결 후 검증 필요.
- 사용자 직접 증상 진단과 실습 완료 여부는 미수행임.
- Book의 상단 메인 이동 링크는 V1 소스에서 localhost를 127.0.0.1:8000으로 고정함. V2에서는 해당 포털을 제공하지 않으므로 이 링크는 사용하지 않고 Book 주소로 직접 접근함. Book 앱을 수정하지 않고 확인된 UI 제한으로 남김.
- V1 requirements의 전이 의존성까지 고정한 재빌드, 공급망 보안·영속 registry·외부 백업 복원은 후속 검토 범위임.
- N100 운영 배포, 운영 데이터·Secret 사용, 물리 HA 검증은 수행하지 않음.

## 6. 후속 조치

비공개 Git 인증 승인 후 GitOps 실증·CI·최종 독립 검토를 완료하고 PR 병합 및 병합 후 상태를 확인함. localhost는 사용자가 확인할 수 있도록 실행 상태를 유지함.
